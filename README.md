# 📝 To-Do List

Aplicação de lista de tarefas desenvolvida com foco em organização e interatividade, permitindo adicionar, remover e gerenciar tarefas de forma simples e eficiente.

---

## 🚀 Funcionalidades

* ➕ Adicionar tarefas com data personalizada (dia, mês e ano)
* ❌ Remover tarefas dinamicamente
* ⚡ Atualização em tempo real sem recarregar a página
* 🧠 Interface interativa com manipulação do DOM

---

## 🛠️ Tecnologias

* HTML
* CSS
* JavaScript

---

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais do JavaScript, como manipulação do DOM, eventos e atualização dinâmica da interface.
